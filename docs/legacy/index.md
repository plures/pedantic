# Legacy documentation

This section preserves historical designs, migration plans, legacy PowerShell
guidance, and superseded extension proposals. It is retained for context and
should not be read as the current release contract.

For supported features, use the [documentation index](../index.md), especially
the native [core module reference](../reference/core-modules.md) and
[governed-operation guides](../guides/governed-remediation.md).

Historical documents remain here unchanged so links in old discussions and
release records can be followed. They may describe planned, replaced, or
unsupported behavior.
