# Dynamic Inventory View

Inventory, host-fact collection, and configuration remediation are unavailable until the extension is connected to a Pedantic service backend. The **Pedantic Inventory** Explorer view explicitly displays this state and exposes no inventory, fact-gathering, or configuration-push commands.

Future service integration will render typed inventory observations and durable operation projections. A configuration remediation will require an immutable revision digest, target identity, approval and effect authorization evidence, and will display service-projected progress, cancellation, final evidence, and review, reboot, disconnection, and expired-authorization states.
